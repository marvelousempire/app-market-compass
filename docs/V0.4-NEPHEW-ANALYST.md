# Market Compass v0.4 — Nephew Multi-Model Analyst

v0.4 adds a grounded AI interpretation layer without allowing a language model to replace or
silently modify Market Compass calculations.

## Product contract

Market Compass calculates market evidence. Nephew interprets that evidence. Each interpretation
receives an immutable report packet and returns a validated response containing both sides,
invalidation, missing information, citations, and a model receipt tied to the report hash.

The always-available `grounded-offline` provider is deterministic. It proves the API and UI
contract without a model, network request, account, or credential. Real providers appear as soon
as their environment configuration is present.

## Provider routes

| Provider ID | Intended lane | Environment prefix |
| --- | --- | --- |
| `nephew-m5` | Five Mac M5 Max / MLX | `NEPHEW_M5_*` |
| `nephew-dgx` | DGX Spark / vLLM | `NEPHEW_DGX_*` |
| `ollama` | bounded compatibility/recovery | `OLLAMA_*` |
| `openai-pro` | OpenAI Responses API, pro reasoning | `OPENAI_*` |
| `anthropic` | Anthropic Messages API | `ANTHROPIC_*` |
| `perplexity` | Perplexity research | `PERPLEXITY_*` |
| `xai` | xAI Responses API | `XAI_*` |

Local OpenAI-compatible routes use `*_API_BASE`, `*_MODEL`, and optional `*_API_KEY`. Cloud
routes require their provider API key. Model IDs are configurable because access and model
catalogs change independently of the application.

Local `*_API_BASE` values include the compatibility prefix (normally `/v1`). Cloud calls require
both `MARKET_COMPASS_CLOUD_ENABLED=true` at server startup and `cloud_allowed: true` on the
individual request. The deployment flag is a fail-closed commissioning control, not a replacement
for App Approval Engine authorization.

Secrets never belong in this repository. On macOS, use Keychain-backed service startup that
injects environment variables. On DGX or other portable runtimes, inject environment variables
through the service manager. Manifest/configuration files may reference variable names only.

## Privacy and authority

Cloud providers are ineligible unless the request explicitly sets `cloud_allowed: true`.
The browser expresses this as **Allow this report to leave the local network**. Production Nephew
routing must additionally enforce App Approval Engine authorization; UI consent alone is not an
authority boundary.

The Five Mac model server should remain on localhost. A private network proxy should expose the
Nephew/Tower gateway rather than raw MLX. DGX vLLM should likewise remain behind Nephew routing.

## API

```text
GET  /api/analyst/health
GET  /api/analyst/providers
POST /api/analyst
GET  /api/symbols?q=HYPE
```

Example analyst request:

```json
{
  "report": {"symbol": "HYPE", "layers": {}},
  "question": "What is the strongest case against this setup?",
  "provider": "auto",
  "depth": "deep",
  "cloud_allowed": false
}
```

## Friendly symbols

Users type `HYPE`, `BTC`, `ETH`, `NVDA`, or `AAPL`. The symbol-search endpoint returns provider
matches and the existing market-data adapter resolves provider-specific identifiers such as
`HYPE-USD`. The friendly symbol remains visible while `resolved_symbol` remains in provenance.
